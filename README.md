# vice-run-support

Official Vice Run support and privacy pages. Contact: alexcaphu@icloud.com. This repository contains only the public website, not the game source.

Enable Settings → Pages → Deploy from a branch → main → /(root) → Save.

After successful deployment:
- Support URL: https://alexcaphu-prog.github.io/vice-run-support/
- Privacy Policy URL: https://alexcaphu-prog.github.io/vice-run-support/privacy.html

Verify both pages are publicly accessible before using them in App Store Connect.
